Pascal is a programming language in which it is convenient to learn to turn a problem into a sequence of precise commands. It appeared in the 1970s and was created by Niklaus Wirth.
Pascal matters not only as a language, but also as a way to understand the basics: how to store data, perform calculations, and control program flow.

**A language has three aspects:**
- Alphabet — the symbols used to write code
- Syntax — the rules for combining those symbols into commands
- Semantics — the meaning of commands, that is, what they do when executed

For example, `x := 5;` puts the value `5` into the variable `x`.
The expression `x = 5` usually checks whether `x` and `5` are equal; the result is `True` or `False`.

An **identifier** is the name of an element in a program: a variable, constant, or function. You can use different names, such as `age`, `total`, or `number1`.

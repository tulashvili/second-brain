title: HTTP 405 Method Not Allowed
---
The 405 Method Not Allowed response code means that the server understood and recognized the HTTP request, but using that method for the specified resource is not allowed.

In other words, the address exists and the server is running, but you tried an action that is not allowed there — for example, sending `POST` instead of `GET`).

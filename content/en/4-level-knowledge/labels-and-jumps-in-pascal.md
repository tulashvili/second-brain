title: Labels and Jumps in Pascal
translationKey: metki-i-perehody-v-pascal
---
**Labels** make it possible to mark a command that a program can jump to with `goto`. In ordinary programs, it is better not to use `label` and `goto`: jumps can make the order of code execution confusing.

Usually, a task is easier to express with `if` and [[control-flow|loops]]—this makes program flow easier to read and verify.

> [!tldr] In brief
> Before building a network, decide its shape and which devices it must connect.

Before building a computer network, I want to identify a few things that have to be planned first.

Start with the network's shape and the devices it needs to connect.

## Organizing a computer network

This means designing, installing, configuring, and managing the network. Common network sizes include:

- [[local-area-network|LAN]]
- [[campus-area-network|CAN]]
- [[personal-area-network|PAN]]
- [[MAN (Metropolitan Area Network)]]
- [[WAN (Wide Area Network)]]

## Network devices

Devices can be classified in several ways:

- **By purpose**
  - End devices are used directly by people: computers, phones, printers, and similar devices.
  - Network devices keep the network running: servers, routers, switches, and others.
- **By connection type:** wired or wireless.
- **By [[osi-model|OSI model]] layer**
  - [[osi-physical-layer|Physical layer]]
    - Cables
    - Antennas
    - Interfaces
    - And so on
  - [[Канальный уровень модели OSI|Data link layer]]
    - Network adapters
    - [[network-switch|switches]]
    - Bridges
    - And so on
  - [[Сетевой уровень модели OSI|Network layer]]
    - [[маршрутизатор|routers]]

> [!tldr]
> **Главная идея:** программа не обязана выполнять каждую команду строго по порядку один раз. Она может **выбрать действие** по условию или **повторить действие** несколько раз. Здесь «нелинейные» описывает ход выполнения программы, а не форму математической функции.
## 1. Условный оператор `if`

Сначала программа вычисляет условие. Например, при `age = 20` выражение `age >= 18` даёт `True`. Затем `if` направляет выполнение в нужную ветку:

```pascal
  if age >= 18 then
    WriteLn('Доступ разрешён') // Точка с запятой здесь ЗАПРЕЩЕНА, так как далее следует else
  else
    WriteLn('Доступ запрещён');
```

`then` означает «тогда», `else` — «иначе». При `age = 20` напечатается первая строка; при `age = 16` — вторая. Это **полное ветвление**: действие предусмотрено для обоих результатов проверки.

Если при ложном условии ничего делать не нужно, используют **неполное ветвление**:

```pascal
if score >= 80 then
  WriteLn('Проверить событие');
```

При `score = 85` сообщение появится. При `score = 50` программа просто перейдёт к следующей команде.
### Несколько действий в одной ветке

После `then` или `else` без дополнительных средств стоит **один оператор**. Чтобы выполнить несколько команд как единое действие, их объединяют в **составной оператор**, или блок, между `begin` и `end`:

```pascal
if score >= 80 then
begin
  WriteLn('Проверить событие');
  WriteLn('Сохранить результат проверки');
end
else
  WriteLn('Обычная обработка');
```

Перед `else` точку с запятой после `end` **не ставят**: иначе условный оператор закончится до ветки `else`.
### Вложенные условия и `else if`
Условия можно проверять последовательно:

```pascal
if score >= 80 then
  WriteLn('Высокий')
else if score >= 40 then
  WriteLn('Средний')
else
  WriteLn('Низкий');
```

Для `score = 55` первая проверка ложна, вторая истинна, результат — `Средний`. Третья ветка уже не выполняется. Если `if` вложен в другой `if`, `else` связывается с ближайшим подходящим `if`; блоки `begin ... end` помогают явно показать нужную связь.
## 2. Условная операция: выбрать значение

Иногда нужно выбрать не целый блок действий, а **одно значение**. В конспекте для PascalABC.NET показана такая запись:

```PascalABC.NET
var smaller := if a < b then a else b;
```

При `a = 7`, `b = 11` условие истинно, поэтому `smaller = 7`. В конспекте также дана форма `условие ? значение1 : значение2`, знакомая по языкам семейства C. Это именно **выражение, возвращающее значение**; `if` из предыдущего раздела управлял выполнением операторов. Значения двух веток должны иметь совместимые типы.
## 3. Выбор из нескольких вариантов: `case`
Когда одно значение нужно сопоставить с несколькими вариантами, удобно использовать `case`:

```
case month of
  3..5: Print('Весна');
  6..8: Print('Лето');
  9..11: Print('Осень');
  12, 1, 2: Print('Зима');
else
  Print('Неверный номер месяца')
end;
```

`month` здесь — **переключатель**, то есть значение, по которому выбирают ветку. `3..5` означает диапазон от 3 до 5 включительно; запятые перечисляют отдельные значения. Если `month = 4`, подходит первая ветка и выводится `Весна`. Если `month = 13`, ни один список не подходит и выполняется `else`.

Такой выбор можно записать и цепочкой `if ... else if`, но `case` нагляднее, когда проверяется **одно значение** на совпадение со списками или диапазонами.
## 4. Цикл: повторить действия

**Цикл** состоит из условия или счётчика в заголовке и **тела** — команд, которые повторяются. Один проход по телу называется **итерацией**. Эта идея уже освещалась здесь — [[Управление последовательностью действий]]; теперь рассмотрим, _когда именно_ заканчивается повторение.

### `loop`: известно число повторов, номер не нужен

`loop` — конструкция PascalABC.NET для заданного количества проходов:

```
var sum := 0;
loop 6 do
  sum += ReadInteger;
Print(sum);
```

Если ввести `2, 4, -1, 3, 0, 5`, значения `sum` после каждого ввода будут `2 → 6 → 5 → 8 → 8 → 13`. Результат — `13`. Номер прохода программе не понадобился.

### `for`: известен диапазон счётчика

```
for var i := 2 to 4 do
  Print(i);
```

Здесь `i` — **параметр цикла**, или счётчик. Он последовательно принимает `2`, `3`, `4`; тело выполняется три раза. Для целых границ с шагом 1 число проходов равно `конец − начало + 1`, если начало не больше конца. В нашем примере: `4 − 2 + 1 = 3`.

Обратный ход задаётся словом `downto`:

```
for var i := 5 downto 3 do
  Print(i);  // 5 4 3
```

В конспекте есть и вариант с явно заданным шагом:

```
for var i := 5 to 13 step 3 do
  Print(i);  // 5 8 11
```

После `11` следующим было бы `14`, но оно выходит за верхнюю границу `13`. При неподходящем направлении границ тело может не выполниться ни разу. Переменная счётчика, объявленная прямо в заголовке через `var`, недоступна вне своей области действия.

### `while`: проверка **до** действия

```
var n := ReadInteger;
var sum := 0;

while n <> 0 do
begin
  sum += n;
  n := ReadInteger;
end;

Print(sum);
```

`<>` означает «не равно». Для ввода `3, 5, 0` происходит следующее:

1. `3 <> 0` истинно → прибавляем 3, читаем 5.
2. `5 <> 0` истинно → сумма становится 8, читаем 0.
3. `0 <> 0` ложно → тело не выполняется, печатается 8.

Если первым введено `0`, тело не выполнится ни разу. Число проходов заранее неизвестно. Важно менять данные, влияющие на условие: если оно навсегда остаётся истинным, цикл не закончится.

### `repeat ... until`: проверка **после** действия

```
var sum := 0;
var n: integer;

repeat
  n := ReadInteger;
  if n <> 0 then
    sum += n;
until n = 0;

Print(sum);
```

Здесь программа сначала читает число и только потом проверяет `n = 0`. Поэтому тело выполнится **хотя бы один раз**. Для `3, 5, 0` сумма тоже равна 8. В примере таблицы конспекта обе формы цикла суммируют ввод до нуля, но организуют первое чтение по-разному. `repeat ... until` полезен, когда условие нельзя проверить до первого действия, например до первого ввода.

Различие легко запомнить:

- `while условие do` — **продолжать, пока условие истинно**;
- `repeat ... until условие` — **закончить, когда условие истинно**.

### Досрочный выход и пропуск части тела

`break` немедленно завершает текущий цикл. `continue` пропускает остаток текущей итерации: в `for` управление переходит к следующему значению счётчика, в `while` — к новой проверке условия, в `repeat` — к проверке после `until`.

**Вложенный цикл** — цикл внутри другого. Например, внешний цикл проходит по двум строкам, а внутренний — по трём столбцам. Действие во внутреннем теле выполнится `2 × 3 = 6` раз. Термин есть в глоссарии и твоей карте темы 1, хотя отдельного подробного примера вложенных циклов в этом конспекте нет.

## Итог

> [!summary]
> `if` выбирает по условию, `case` выбирает по значению, `loop` и `for` повторяют действия заданное число раз, `while` проверяет условие перед повтором, а `repeat ... until` — после. Все содержательные разделы конспекта и его итоговая таблица циклов разобраны.

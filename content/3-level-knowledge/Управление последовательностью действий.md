Выделяют три способа управления последовательностью действий:

## Следование
**Следование** - команды выполняются одна за другой
```pascal
sum := a + b;
writeln(sum);
```
## Ветвление
**Ветвление** - программа выбирает, что делать, в зависимости от условия:
```pascal
if age >= 18 then
    writeln('Совершеннолетний')
else
    writeln('НеСовершеннолетний');
```
## Цикл
**Цикл** - команда или блок повторяются. Цикл с параметром подходит, когда число повторов известно заранее:
```pascal
for i := 1 to 5 do
    writeln(i);
```

Цикл `while` проверяет условие перед каждой итерацией, поэтому тело может не выполниться ни разу. 
Цикл `repeat ... until` сначала выполняет тело, а потом проверяет условие, поэтому оно выполняется хотя бы один раз. 
Цикл внутри другого цикла называется **вложенным**;  так, например, можно перебрать строки и столбцы таблицы.

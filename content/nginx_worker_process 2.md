Один из самых основных параметров для конфигурации производительности Nginx.  
Он позволяет регулировать количество процессов nginx, которые будут запущены одновременно  
  
- `auto` - установит идентичное количество процессов, что и количество ядер. это наиболее популярная настройка  
- `n` - если указать количество процессов меньше количества ядер, то nginx будет использовать конкретно указанное количество

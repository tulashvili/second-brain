### пара ключей
Каждая пара ключей состоит из открытого и закрытого ключа. 
Открытый ключ используется для шифрования сообщений, которые можно расшифровать только закрытым ключом.

Открытый ключ загружается на удаленный сервер, к которому необходимо получить доступ. 
Сам ключ нужно добавить в специальный файл ~/.ssh/authorized_keys.

Далее, когда клиент попытается выполнить проверку подлинности через этот ключ, сервер отправит сообщение, зашифрованное с помощью открытого ключа, если клиент сможет его расшифровать и вернуть правильный ответ - аутентификация пройдена.
#### форматы ключей
[[ssh key Ed25519]] обеспечивает высокий уровень безопасности, устойчив к атакам по сторонним каналам (например, по времени выполнения). RSA требует очень длинных ключей (\(3072\) или \(4096\) бит) для обеспечения эквивалентной защиты, в то время как Ed25519 использует всего 256 бит.

**То есть:** Ed25519 более короткий при той же эффективности, что и у id_rsa



## Конфигурация

### Сетевые настройки

Определяют, на каких сетевых интерфейсах и портах SSH-сервер принимает подключения.

| Параметр        | Назначение                                    | Текущее значение | Возможные значения / формат                                                     |
| --------------- | --------------------------------------------- | ---------------- | ------------------------------------------------------------------------------- |
| `Port`          | TCP-порт, на котором SSH принимает соединения | `22`             | Целое число `1–65535`. Например, `22`, `2222`. Можно указать несколько значений |
| `AddressFamily` | Определяет используемые семейства IP-адресов  | `inet`           | `any` — IPv4 и IPv6; `inet` — только IPv4; `inet6` — только IPv6                |

**Особенность:** `AddressFamily inet` полностью отключает прослушивание IPv6. Это не универсальное требование hardening, а архитектурное решение.
### **Аутентификация**

|Параметр|Значение|Зачем|
|---|---|---|
|`PermitRootLogin`|`no`|Запретить прямой вход под root|
|`PasswordAuthentication`|`no`|Отключить аутентификацию паролем|
|`PermitEmptyPasswords`|`no`|Запретить пустые пароли|
|`PubkeyAuthentication`|`yes`|Разрешить аутентификацию по SSH-ключам|
|`MaxAuthTries`|`4`|Ограничить количество попыток аутентификации|
|`LoginGraceTime`|`30`|Ограничить время на прохождение аутентификации|

### **Управление сессиями**

|Параметр|Значение|Зачем|
|---|---|---|
|`ClientAliveInterval`|`300`|Проверять активность клиента каждые 300 секунд|
|`ClientAliveCountMax`|`2`|Ограничить число пропущенных ответов клиента|
|`MaxSessions`|`5`|Ограничить количество сессий в одном SSH-соединении|
|`X11Forwarding`|`no`|Отключить перенаправление графических приложений|
|`AllowTcpForwarding`|`no`|Запретить TCP-туннелирование, если оно не требуется|
|`AllowAgentForwarding`|`no`|Запретить перенаправление SSH-агента, если оно не требуется|

### **Аудит и криптография**

Определяют, какие алгоритмы используются для обмена ключами, шифрования соединений, проверки целостности и аутентификации сервера.

| Параметр                  | Пример значения                                                                           | Зачем                                                     |
| ------------------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| `LogLevel`                | `VERBOSE`                                                                                 | Расширить журналирование SSH-событий                      |
| `PermitUserEnvironment`   | `no`                                                                                      | Запретить пользовательские переменные окружения через SSH |
| `HostbasedAuthentication` | `no`                                                                                      | Отключить аутентификацию на основании доверия к хостам    |
| `KexAlgorithms`           | `sntrup761x25519-sha512@openssh.com`, `curve25519-sha256`, `curve25519-sha256@libssh.org` | Использовать допустимые алгоритмы обмена ключами          |
| `Ciphers`                 | `ChaCha20-Poly1305, AES-GCM`                                                              | Определяет алгоритмы симметричного шифрования SSH-трафика |
| `MACs`                    | HMAC-SHA2, UMAC с Encrypt-then-MAC                                                        | Определяет алгоритмы проверки целостности SSH-сообщений   |

| Параметр                   | Назначение                                                                                    | Текущее значение                 | Возможные значения / формат                                                                        |
| -------------------------- | --------------------------------------------------------------------------------------------- | -------------------------------- | -------------------------------------------------------------------------------------------------- |
| `HostKey`                  | Указывает путь к приватному ключу, идентифицирующему SSH-сервер                               | ED25519, RSA                     | Абсолютный путь к файлу. Например, `/etc/ssh/ssh_host_ed25519_key`. Допускается несколько директив |
| `KexAlgorithms`            |                                                                                               |                                  | Список алгоритмов через запятую. Поддерживаются модификаторы `+`, `-`, `^`                         |
| `Ciphers`                  |                                                                                               |                                  | Список алгоритмов через запятую. Например, `aes256-gcm@openssh.com,aes128-gcm@openssh.com`         |
| `MACs`                     |                                                                                               |                                  | Список алгоритмов через запятую. Например, `hmac-sha2-256-etm@openssh.com`                         |
| `HostKeyAlgorithms`        | Ограничивает алгоритмы, которые сервер использует для подтверждения своей подлинности         | ED25519, RSA-SHA2                | Список алгоритмов через запятую. Например, `ssh-ed25519,rsa-sha2-512`                              |
| `PubkeyAcceptedAlgorithms` | Определяет допустимые алгоритмы подписей при аутентификации пользователей по публичному ключу | ED25519, FIDO2 ED25519, RSA-SHA2 | Список алгоритмов через запятую. Например, `ssh-ed25519,rsa-sha2-512`                              |

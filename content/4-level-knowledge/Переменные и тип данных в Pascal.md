**Переменная** — это именованное место для значения, которое может меняться во время работы программы. 
Её объявляют после `var`, указывая имя и тип. Можно давать разные имена, например, `age`, `total` или `number1`. 
```pascal
var
  count: integer;
  temperature: real;
  answer: boolean;
```

**Тип данных** определяет, какие значения можно положить в переменную и какие действия с ними доступны.

```pascal
var
    age: integer;
    price: real;
    isReady: boolean;
```
Здесь `age` хранит целое число, `price` — число с дробной частью, `isReady` — логическое значение: истина или ложь. Объявление переменных помогает заранее описать данные, с которыми будет работать программа.

Можно объявить несколько переменных одного типа в одной строке, перечислив их через запятую:
```pascal
var
  x, y, result: integer;
```

Если значение не должно меняться в ходе выполнения программы, используют **константу**. Её описывают после `const`:
```pascal
const
  Gravity = 9.81;
```
Имя константы делает код понятнее: ускорение свободного падения на Земле составляет примерно 9.81.

Типичная программа состоит из описаний и блока команд:
```pascal
program Greeting;

var
  name: string;

begin
  readln(name);
  writeln('Привет, ', name);
end.
```

Допустим, нужно найти сумму двух чисел. Сначала задаём алгоритм: получить два числа, сложить их, показать результат:

```pascal
var
  a, b, sum: integer;

begin
  readln(a, b);
  sum := a + b;
  writeln(sum);
end.
```

В этом примере ввод — `readln`, вычисление — `a + b`, присваивание результата переменной — `:=`, вывод — `writeln`. Так связаны основные понятия курса: алгоритм, переменные, типы, операторы и структура программы.

## Раздел описаний программы
В программе на Pascal раздел описаний сообщает компилятору, с какими данными и дополнительными средствами будет работать программа. Он находится **перед `begin`**, то есть до основного блока команд:
```pascal
programm Circle;

const
    Pi = 3.14159;

var
    radius, area: real;

begin
    area:= Pi * radius * radius;
    writeln(area);
end;
```
Здесь описаны константа `Pi` и переменные `radius`, `area`. Команды между `begin` и `end.` уже выполняют вычисления и вывод.

### Порядок подразделов в классическом Pascal
Порядок подразделов в классическом Pascal обычно строго регламентирован - может повторяться или комбинироваться в определенных диалектах. 
Не каждый из них нужен в каждой программе. Для простой задачи может хватить только `var`, а может не понадобиться и он — например, если программа работает только с константами и командами.

| Раздел                                                            | Описание                               | Назначение                                                                                                             | Пример                                          |
| ----------------------------------------------------------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| `label` - [[Метки и переходы в Pascal]]                           | Описание меток                         | Используется для объявления числовых или символьных меток, к которым можно сделать переход с помощью оператора `goto`. | `label 10, 20, start;`                          |
| `const` — [[Переменные и тип данных в Pascal]]                    | Описание констант                      | Задаёт постоянные значения, которые не меняются в ходе выполнения программы.                                           | `const Pi = 3.1415; MaxSize = 100;`             |
| `type` — Типы, процедуры и функции в Pascal                   | Описание пользовательских типов данных | Позволяет создавать собственные типы данных: перечисляемые, интервальные, записи, массивы, классы.                     | `type Days = (Mon, Tue, Wed);`                  |
| `var` — [[Переменные и тип данных в Pascal]]                      | Описание переменных                    | Объявляет переменные с указанием их типа данных, чтобы компилятор выделил под них память.                              | `var x, y: integer; name: string;`              |
| `procedure` и `function` — Типы, процедуры и функции в Pascal | Описание подпрограмм                   | Используются для объявления собственных процедур и функций, которые можно вызывать в теле программы.                   | `procedure Hello; begin writeln('Hello'); end;` |
### Чтение раздела описаний программы
На раздел описаний программы полезно смотреть как на перечень заранее объявленных ресурсов программы:

1. Что подключено через `uses`?
2. Какие значения заданы как постоянные через `const`?
3. Какие переменные перечислены после `var` и каких они типов?
4. Есть ли собственные типы, процедуры и функции?
5. Где заканчиваются описания и начинается выполнение — у `begin`?

> [!important] Главное правило
> Прежде чем использовать переменную или константу в командах, её обычно нужно объявить выше, в соответствующем разделе описаний.
